## 🚀 Quick Start

### Prerequisites

- Python ≥ 3.10
- Node.js ≥ 18.x
- pip or npm
- Redis (for caching)

```bash
# Install dependencies
pip install -r requirements.txt
npm install

# Run migrations and seed data
python manage.py migrate
python manage.py makemigrations
python manage.py migrate
python manage.py seed_languages
python manage.py createsuperuser --username admin --email admin@shop.com

# Start the development server
python manage.py runserver 0.0.0.0:8000
```

### Running Tests

```bash
pytest
```

## 🗺️ Architecture Overview

| Component | Technology | Purpose |
|-----------|------------|---------|
| **Backend** | Django 5.x | Core application logic, admin panel, API |
| **Frontend Framework** | React 18+ | Product listing, cart, checkout, blog UI |
| **Database** | PostgreSQL (SQLite for dev) | Relational data: users, products, orders, reviews |
| **Cache** | Redis | Session storage, product caching, rate limiting |
| **Search Engine** | Elasticsearch / Algolia | Full-text search across products and categories |

## 📦 Key Features

### Core E-commerce
- Product catalog with variants (size, color, material)
- Multi-currency pricing engine
- Discount & promo code system
- Inventory management with low-stock alerts
- Order management (user + admin dashboards)
- Reviews, ratings, and Q&A system
- Wishlist and product comparison

### User Experience
- Session-based shopping cart
- Checkout with address validation
- Shipping zones and rates
- Payment integration (Stripe/PayPal/Razorpay)
- Email notifications for orders & refunds
- Guest checkout support

### Content Management
- Blog posts with SEO optimization
- Sitemap generation
- Social proof (reviews, ratings)
- Search with faceted filtering
